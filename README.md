# Descargas de Radamant

Lo que sirve `https://descargas.radamant.eu`: los programas que se instalan, su firma y sus páginas. Aquí no hay código.

- `mentor/`: la app de Mentor para Windows. `ultima.json` dice cuál es la última versión y `ultima.json.firma` la firma de Radamant; la app no instala nada que no lleve esa firma.

Lo publica `herramientas/publicar` del repositorio de Mentor.
